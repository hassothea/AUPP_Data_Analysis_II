1.2 ACF and PACF Recap

  • ACF (Autocorrelation Function): measures the correlation between a time series and its lagged values.
  • PACF (Partial Autocorrelation Function): measures the correlation between a time series and its lagged values after removing the effects of shorter lags.

\(n\) is the number of observations and \(\widehat{X}_t=\sum_{j=1}^{k-1}\hat{\beta}_jX_{t-j}\) is the predicted value of \(X_t\) using its lags \(1,...,k-1\).

import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots
from statsmodels.tsa.stattools import acf, pacf

BLUE, GREY = "#2E6FDB", "#4A4A4A"


def add_corr_plot(fig, values, conf, lags, row, col, title):
    """Stem plot + shaded confidence band, like statsmodels' plot_acf/plot_pacf.
    values: correlation per lag; conf: (n_lags, 2) CI already centred at 0."""
    # Confidence band (shaded area)
    fig.add_trace(go.Scatter(x=lags, y=conf[:, 1], mode="lines",
                             line=dict(width=0), hoverinfo="skip",
                             showlegend=False), row=row, col=col)
    fig.add_trace(go.Scatter(x=lags, y=conf[:, 0], mode="lines",
                             line=dict(width=0), fill="tonexty",
                             fillcolor="rgba(46,111,219,0.15)",
                             hoverinfo="skip", showlegend=False),
                  row=row, col=col)
    # Stems (thin bars) + dots on top
    fig.add_trace(go.Bar(x=lags, y=values, width=0.08, marker_color=BLUE,
                         showlegend=False, hoverinfo="skip"), row=row, col=col)
    fig.add_trace(go.Scatter(x=lags, y=values, mode="markers",
                             marker=dict(color=BLUE, size=8),
                             showlegend=False,
                             hovertemplate="lag %{x}<br>%{y:.3f}<extra></extra>"),
                  row=row, col=col)
    fig.update_xaxes(title_text="Lag", showgrid=False, zeroline=False,
                     dtick=5, row=row, col=col)
    fig.update_yaxes(title_text=title, range=[-1.05, 1.05], gridcolor="#F0F0F0",
                     zerolinecolor="#999999", row=row, col=col)


def plotly_acf_pacf(y, nlags=20, alpha=0.05, title=None, side_by_side = True, height = 210, width = 950):
    n = len(y)
    lags = np.arange(nlags + 1)

    # ACF with Bartlett confidence intervals (centred at zero, as in statsmodels)
    acf_vals, acf_ci = acf(y, nlags=nlags, alpha=alpha, fft=False)
    acf_ci = acf_ci - acf_vals[:, None]

    # PACF with the usual +/- z / sqrt(n) band
    pacf_vals = pacf(y, nlags=nlags, method="ywm")
    z = 1.959963984540054  # norm.ppf(1 - alpha/2) for alpha = 0.05
    band = z / np.sqrt(n)
    pacf_ci = np.column_stack([-band * np.ones(nlags + 1),
                               band * np.ones(nlags + 1)])
    if side_by_side:
        fig = make_subplots(rows=1, cols=2, horizontal_spacing=0.08,
                        subplot_titles=("Autocorrelation (ACF)",
                                        "Partial Autocorrelation (PACF)"))
        add_corr_plot(fig, acf_vals, acf_ci, lags, 1, 1, f"ACF of {title}")
        add_corr_plot(fig, pacf_vals, pacf_ci, lags, 1, 2, f"PACF of {title}")
    else:
        fig = make_subplots(rows=2, cols=1, horizontal_spacing=0.08,
                        subplot_titles=("Autocorrelation (ACF)",
                                        "Partial Autocorrelation (PACF)"))
        add_corr_plot(fig, acf_vals, acf_ci, lags, 1, 1, f"ACF of {title}")
        add_corr_plot(fig, pacf_vals, pacf_ci, lags, 2, 1, f"PACF of {title}")
    

    fig.update_layout(template="plotly_white", paper_bgcolor="white",
                      plot_bgcolor="white", height=height, width=width,
                      font=dict(family="Helvetica, Arial, sans-serif",
                                color=GREY),
                      margin=dict(l=50, r=30, t=20, b=20))
    for a in fig.layout.annotations:
        a.font = dict(size=14, color=GREY)
    return fig

fig_pm25 = plotly_acf_pacf(df['pm2_5'], nlags=25, alpha=0.05, title='PM 2.5 (µg/m³)')
fig_pm25.show()

2 Stationarity in Time Series

2.1 Stationary Time Series

  • A stationary time series is one whose statistical properties (like mean, variance, and autocorrelation) do not change over time.
  • In other words, it does not exhibit trends or seasonal effects.
  • Stationary time series is stable and predictable, making it easier to model and forecast.

Stationarity Detection: Visualization

Stationary Time Series

  • A time series is considered (weakly) stationary if \(\mathbb{E}(X_t) = \mu, \mathbb{V}(X_t)=\sigma^2, \text{Cov}(X_t,X_{t-k})=\gamma_k,\) for all \(t>0\), are all constant over time and depends only on the lag \(k\).
  • Is there a trend or seasonality in the series? (mean).
  • Does it spread wider or shrink down over time? (variance).

Augmented Dickey-Fuller (ADF) Test

Augmented Dickey-Fuller Test

  • The Augmented Dickey-Fuller (ADF) test is a statistical test used to determine whether a time series is stationary or has a unit root (non-stationary).
  • Hypothesis: \(H_0:\) the time series is non-stationary vs \(H_1:\) it’s stationary.
  • Decision at significance level \(\color{red}{\alpha}\):
    • If \(\text{p-value}<{\color{red}{\alpha}}\), the time series is stationary.
    • Else, no evidence to reject non-stationarity of the time series.
from statsmodels.tsa.stattools import adfuller

3 Time Series Transformations

3.1 Transformations

  • Transformations are used to stabilize the variance, making the time series stationary, or reduce influential outliers.
  • Transformations for stabilizing variance:
    • Box-Cox Transformation: for some \(\lambda>0\) and \(X_t>0\): \[\tilde{X}_t=\begin{cases}\frac{X_t^\lambda-1}{\lambda} & \text{if } \lambda \neq 0\\ \ln(X_t) & \text{if } \lambda = 0 \end{cases}\]
    • Square Root Transformation: \(\tilde{X}_t=\sqrt{X_t}.\)
  • Differentiation to remove trend and seasonality:
    • First Order Differentiation: \(\Delta X_t=\Delta^1 X_t=X_t-X_{t-1}.\)
    • \(k\)-order Differentiation: \(\Delta^k X_t=\Delta^{k-1} X_t-\Delta^{k-1} X_{t-1}\).

4 Autoregression (AR) & Moving Average (MA) Models

4.1 Autoregression (AR) Models

  • A natural way to predict the next value of a stationary time series \(X_t\) would be to use its previous values (lags).
  • The simplest form of this is an Autoregression model of degree \(p\), \[X_t={\color{blue}{\phi_0}}+{\color{blue}{\phi_1}} X_{t-1}+{\color{blue}{\phi_2}} X_{t-2}+\cdots +{\color{blue}{\phi_p}} X_{t-p}+\epsilon_t\] for some parameters \({\color{blue}{\phi_j}}\) (to be estimated) and error term \(\epsilon_t\).
  • This means we should look at PACF plot to detect \(\color{blue}{p}\).

AR as Linear Regression

  • AR(\(p\)): \(X_t={\color{blue}{\phi_0}}+{\color{blue}{\phi_1}} X_{t-1}+{\color{blue}{\phi_2}} X_{t-2}+\cdots +{\color{blue}{\phi_p}} X_{t-p}+\epsilon_t\).

Estimating Parameters in AR Models

  • In AR(\(p\)) with parameters \(\color{blue}{\beta}=({\color{blue}{\phi_0}},{\color{blue}{\phi_1}},\ldots,{\color{blue}{\phi_p}})\), we can estimate the parameters using Ordinary Least Squares (OLS): \[\widehat{\beta} = \arg\min_{{\color{blue}{\beta}}}\sum_{t=p+1}^T (X_t - \textbf{X}{\color{blue}{\beta}})^2, \text{ where }\textbf{X} \text{ uses }p\text{ lags of }X_t.\]
  • OLS solution: \(\widehat{\beta}=(\textbf{X}\textbf{X})^{-1}\textbf{X}^TY\), where \({\color{orange}{Y}} = (X_{p+1},\ldots,X_n)^T\).

4.2 Moving Average (MA) Models

  • Another idea for predicting stationary time series \(X_t\) is to use residuals/shocks from each lag of \(X_t\).
  • The simplest form of this is a Moving Average model of degree \(q\), \[X_t={\color{red}{\theta_0}}+{\color{red}{\theta_1}} \epsilon_{t-1}+{\color{red}{\theta_2}} \epsilon_{t-2}+\cdots +{\color{red}{\theta_q}} \epsilon_{t-q}+\epsilon_t\] for some parameters \({\color{red}{\theta_j}}\) (to be estimated) and error term \(\epsilon_t\).
  • This means we should look at ACF plot to detect \(\color{red}{q}\).

MA as Linear Regression

  • MA(\(q\)): \(X_t={\color{red}{\theta_0}}+{\color{red}{\theta_1}} \epsilon_{t-1}+{\color{red}{\theta_2}} \epsilon_{t-2}+\cdots +{\color{red}{\theta_q}} \epsilon_{t-q}+\epsilon_t\).

Estimating Parameters in MA Models

  • In MA(\(\color{red}{q}\)) with parameters \(\color{red}{\theta}=({\color{red}{\theta_0}},{\color{red}{\theta_1}},\ldots,{\color{red}{\theta_p}})\), Ordinary Least Squares (OLS) fails because residual \(\epsilon_t\) are not observed and depend on \(\color{red}{\theta}\).
  • In this case, we use Conditional Least Squares (CLS) + Numerical Iterations to estimate \({\color{red}{\theta}}\).
  • Sum of Squared Residuals: \(\color{red}{\text{SSR}}({\color{red}{\theta}})=\sum_{t=1}^T\epsilon_t^2(\color{red}{\theta})\).
  • We iteratively update \({\color{red}{\theta}}\) to minimize SSR.
    • Initialization: Start with a guess for \({\color{red}{\theta}_0}\).
    • Recursive Filtering: Construct error matrix \({\color{darkgreen}{E}}\) & target \({\color{orange}{Y}}\).
    • Update: \({\color{red}{\theta}_{\text{new}}}=\arg\min_{{\color{red}{\theta}}}\color{red}{\text{SSR}}({\color{red}{\theta}})\) and update \({\color{red}{\theta_0}}={\color{red}{\theta_{\text{new}}}}\).
    • Repeat until convergence.

5 Autoregressive Integrated Moving Average (ARIMA) Models

5.1 ARIMA(p,d,q) Model

  • ARIMA(\(p,d,q\)) combines autoregression, differencing, and moving-average components:
    • (\(p\)): AR order, guided by PACF.
    • (\(d\)): differencing order, guided by stationarity (ADF test).
    • (\(q\)): MA order, guided by ACF.
  • To compare models, use AIC and BIC criteria: lower values indicate better fit. For candidate parameter (\(\widehat{p},\widehat{d},\widehat{q}\)):
    • \(\text{AIC}=-2\log L(\widehat{p},\widehat{d},\widehat{q})+2k\),
    • \(\text{BIC}=-2\log L(\widehat{p},\widehat{d},\widehat{q})+k\log n\), where \(k\) is the number of parameters, \(n\) is the sample size.
